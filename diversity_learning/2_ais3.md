## 契機與伏筆
高二下學期，我因研究自製全端網站而對資安產生興趣，於是報名了 AIS3 Junior。出發前一週，我想說提前熟悉linux就把筆電系統全刪換成 Linux Ubuntu，沒想到這個決定差點要了我的命。
AIS3簡介：
`AIS3是由教育部資訊安全人才培育計畫推動的暑期資安培訓課程，自2015年起舉辦，旨在培養學生的資安實務能力。課程涵蓋網頁安全、軟體安全、數位鑑識等領域，並透過密集訓練與實作提升學員技能。錄取方式包含資安測驗與甄選，適合具備基礎資安知識的學生參與。此外，AIS3 Junior 針對高中職學生提供基礎資安課程，推動資安教育向下扎根`
## 過程
### day0暴風雨前的平靜&&暴風雨 -關於我被暴風雨淋成落湯雞
第零天（提前準備日），下午我就一個人搭高鐵南下到了嘉義，並跟一樣參加ais3的陌生人併車到了會場-中正大學

#### 第一個&&第二個麻煩
這時候我遇到了第一個麻煩，老師突然在群組請我們先準備虛擬機，他給了我們映像檔，請我們下載VMware啟動，但我突然發現linux系統配置VMware有夠麻煩，我自己坐在食堂角落搞了1個多小時都沒搞定，不過還挺愜意的，大家都各自打著電腦，坐在某個角落，直到我發現了第二個問題：我的變壓器沒帶到3pin電源線，也就是說我的筆電沒辦法充電了，但幸好我後來發現手機變壓器也勉強能用。反正過了一陣子，我們就進講堂聽宣導事項了

吃完飯後回來，我裝了virtual box(另一款虛擬機軟體)取代老師要求的vmware，然後看能啟動系統就跑去寫溼透了的數學暑假作業了。晚上就又是另一個煎熬，因為我們只有床板，我又沒有氣墊只有睡袋，再加上我亂喝奶茶肚子痛，我到了3點以後才睡著

### day1系統崩潰 -第一天就後悔

#### CTF&&VPN
一大早我就精神跟身體都很糟糕地起床跟室友一起去講堂，準備上課。第一堂課是教我們操作kali linux，這對提前把電腦直接換成linux的我來說是小菜一碟，直到他開始讓我們ctf
```
ctf:catch the flag 是一種資安活動 一般是把一段密碼flag藏在系統的某個地方讓參加者破解
```
我們ctf的活動是要在他們給我們的kali linux系統資料裡面找到隱藏的flag然後上傳到網路上的記分平台，這時候我遇到了一個問題，他們的記分網站跟其他靶機(給我們測試攻擊的主機)是架設在vpn內的，而開始上課後助教請我們加入vpn，但是他們使用的open vpn在linux雖然有軟體但沒有圖形介面，我搞了很久很久還是無法加入他們的vpn，不是因為命令行的東西，而是我找不到那個群組功能，或是其實根本沒有，反正助教看我一直沒加入過來看了我一下，但看我用linux在自己作死就不管我了

直到上半堂課上完進入午餐時間我都還沒搞定vpn的問題，助教們也放棄我了，無助再加上沒睡好，這時候我已經有點小崩潰了，正當我考慮要直接重灌系統卻還在想linux要怎麼做啟動usb時，我的隊友：施信佑直接給了我一個一堆系統的啟動usb，完成了一個完美救援，於是我就邊吃飯邊等我的windows11安裝

#### 隊友
- 首先是救了我一命的施信佑，很神奇的是他是我高中的隔壁班同學，但我們也是第零天吃晚餐才知道彼此，他參加過大大小小的程式/資安比賽，是我們組後來專題實作的第二把交椅

- 再來是成功高中的黃同學，好像是什麼資訊社社長，又是什麼演算法協會的總召，反正是一個很厲害的人

其他3個人我比較沒有那麼熟，但也都有一點資安經驗，我跟他們吃飯才發現他們彼此都認識，都是資安圈內人，他們在資安小遊戲的時候就都混熟了，而我還是只認識我的隔壁班同學，這時候我發現這個ais3似乎沒有那麼「新手友善」而我是個完全的資安新手，就有點開始擔心之後的專題實作了


接下來的課是一些資安的基本知識介紹還有網路概論，這部分的知識我都很熟悉的，因為我有自己架設網站跟伺服器的經驗，反而第一天的課就差不多這樣結束了

### day2爆炸 -網路資安初體驗
第二天上午是教網路安全，下午是一點點的ai資安介紹，這天的課程非常有趣，主要是教我們各種入侵網站的方法，我學會了
- broken access control
其實就是找到洩漏的管理員登入方式
- file upload 
這個很有趣，是在網頁的上傳區上傳後端程式碼並讓他執行
- local file inclusion
這個就是找到本地的檔案，並嘗試攻擊
- xss
將前端腳本注入到代碼中，然後利用
- command injection 
跟名字一樣就是注入系統指令
- sql injection 
在資料庫查表的時候注入資料庫程式
- ssti
對模板引擎注入模板並讓他渲染出來
- ssrf
誘導伺服器自己訪問內部數據

這邊為了節省篇幅寫得比較簡略一點，實際上每個的概念都很有趣，且實際解題難度也很大，另外ai課程的部分也挺有趣的，我學會了怎麼用奇形怪狀提示詞騙出開發者不想讓你知道的東西

#### 高難度作業
上課需要有很多先備知識，還好我勉強跟得上，ctf都有把範例題寫完，但是除了範例題還有一堆進階題總共大概25題吧，每題都有點挑戰性，有些題目光是寫就要半個小時一個小時，他還要我們寫解題報告，我想說怎麼可能做得完，這時候又突然聽助教說題目沒做到一定程度可能拿不到證書，於是我就只好硬著頭皮做了

#### 半夜解題
直接跳轉到晚上，我題目只寫了一半，解題報告更是完全沒有寫，於是我開始跟室友共享資料，然後繼續往下破解題目，但只有一個室友比較給力，他破出來了一題，然後我破了3題

我就這樣跟一位室友一起解題到半夜四點多，過程中發現ctf挺有趣的，而且有很高的成就感，讓我想一題接著一題的往下寫，最後甚至睡覺的時候還在想題目，然後隔天早上突然想通並打上了排行榜第七名

### day3莫名奇妙的日出 -減陽壽做專題
這天的課程是上午把昨天的ai資安教完，下午讓我們討論專題跟實作專題

#### 討論&&開工
在討論專題的時候他們討論了快半個小時卻一直沒有結論，而我本來是以一個「我有發表意見了，不要說討論我都沒貢獻」的心態來發表我的想法：**在我的訂單管理網站上加上一個ai助手，然後留下一些常見開發失誤，攻擊組用ai代理完成cve漏洞復現**

想不到我這個只是想交差了事的點子助教們都覺得不錯，隊員也是，我展示了一下我的網站跟講一下細節後我們就開始分工並實作，我是負責網站跟ai助手功能搭建，有人負責研究怎麼調用ai的api，有人負責研究漏洞，有人負責研究如何注入提示詞

我們有結論且分配完工作後已經快要到晚餐時間了，但我們沒有吃飯，而是去全家買個零食趕快回來趕工

我大概花了半個小時就把ai助理的功能範例（這時候還沒接入ai）加入到首頁，這是一個很複雜的功能，也是我第一次做這種前端即時互動，但為什麼我能做這麼快？其實是我直接從ai資安的題目裡把一個ai助理頁面的前端程式複製出來再改一改，然後自己寫一下後端，就直接拿來用了

#### 夜間施工
回宿舍後我們因為還有解題作業跟解題報告要寫，所以決定先全部人專心寫作業到12點，等作業寫完再大家一起搞專題

作業搞定之後負責ai的人寫好程式後我就接入ai，不過他的程式問題很多，我接入也花了很多時間。接下來的幾個小時我在寫ai的提示詞，並且給ai一些特別的功能，比如看時間，看那個網站的商品庫存等等，並且設計開發失誤給攻擊組利用，這個時候已經半夜3點了，但我們全部人都沒有要休息的意思，而是全部在一間宿舍，有的人坐椅子，有的人坐床板，全部人都在拼命趕工
![20240818_002137](https://hackmd.io/_uploads/r1Mdqw6pke.jpg)

後來我就是不斷調適程式，而攻擊組那邊在測試部署，後來我的部分完成的差不多後也去幫忙部署跟幫忙測試提示詞注入，就這樣直接到六點多，並一起出去看日出(沒看到)，但我們還有些東西沒有完成，後來都快要到早上的集合時間了，我們才逼不得已回自己宿舍收拾東西，很瘋狂的是我們一組人沒有一個人有睡覺，而幾個小時後又要去大講台上報告

### day4 歸 -報告與頒獎
直接延續上一天，我回宿舍整理完東西後也沒空洗澡，直接去全家買早餐然後去講堂集合了

到了講堂我們才開始做報告，但不愧全是理工人，我們的報告是真的有夠醜，原本我不負責這塊的都看不下去去幫忙做，不過其實我的程式也還在調校，甚至別人都開始報告了我還在調

#### 上台報告
接下來就是上台報告了，概要介紹完後就是我，我的時間沒有很多，要在很短的時間內介紹完整功能，其實是真的挺緊張的，第一次在那麼大的講台上報告，下面又是一堆專家，甚至是教授，還好我報告沒甚麼失誤。後來就是其他組員介紹系統漏洞跟實現方法，其實實現方法的部分也是我設計的，但報告交給其他組員。報告結束後是問答環節，我負責開發部分的問題，其實我覺得我回答得沒有很好，但評審們好像都接受

#### 頒獎
下臺後人就像散掉了一樣，輕鬆地看著其他組的專題報告，然後靜等結果出爐。我是覺得我們組是有希望得獎的，雖然不是發現什麼重大漏洞之類的壯舉，但相較於其他組我們有趣很多，而且也是唯一有包含這屆新的主題：**AI資安**的一組。專題獎頒發的時候也是有點緊張的，有一種期待，卻又怕期望落空的感覺，第三名，第二名甚至有並列兩個，卻遲遲沒有喊到我們組，我看到受獎的人都會頒發黑帽子，就跟隔壁說：太扯了他們竟然有帽子，我超級想要帽子的，終於到了第一名……其實在筆記開頭就講過了，沒錯，我們組拿了第一名，是有點驚訝的，想不到還真的

可能是因為太累，加上突然的放鬆，又突然的興奮，我整個人有點恍惚，上台在幹什麼我已經忘了，我只記得我怕我穿著的是昨天的衣服被發現，還有他幫我戴帽子的時候戴歪了

#### 意外的大滿貫
後來拍完照下臺後是頒發優秀個人，優秀個人的評分標準是解題的分數跟解題報告，還有小組專題的參與程度，這是因為怕有人都在拼命解題刷分而不理會小組報告，實際上還真的有這種人。我不覺得我能得這個獎，因為我雖然第二天有上前十一陣子，但後來都在忙專題就掉下來了，反而是我的隔壁班同學比較有機會，他在搞專題之前我們也為了讓他得獎給他時間去解題刷分。反正頒獎結果是：我得了他沒得，我是真的完全沒有想到的，但似乎是這次評分標準比較看重專題跟筆記，而剛好組員跟助教還有評審給我的分數都很高，也就這樣，我莫名奇妙成了ais3j2024年度唯一得到最佳專題跟優秀個人的大滿貫學生

## 總結心得與反思

如同前言所說，這是一篇心路歷程，所以心得大部分都跟敘述混在一起了。我覺得這五天我的情緒起伏非常大，從一開始的崩潰，到高壓，以及最後的成就感以及放鬆，以至於它在我心中留下很深的印象，如今都過了半年了我還是能回想起大部分的內容

這是我第一次體驗到小組合作開發的樂趣，雖然是過勞工作幾乎完整的24小時，但它帶給我的滿足感與成就感是遠遠大於疲累的
其實後來聽助教說這屆之所以時間壓力那麼大是因為講師把題目出得太困難，他預設我們都有很多的ctf比賽經驗，所以題目不只太難，還太多。以至於以前可以快速搞定ctf跟筆記然後有整整兩天可以專心搞專題，而我們這屆可能解題時間要多花一倍，並且還要犧牲大部分的休息時間才能播出時間給專題

其實我認為我們的專題還是存在很多問題的，比如說刻意設計的提示詞漏洞，以及調用系統功能的方法，但我們主要贏的地方是我們有趣的核心想法，以及實際把它做出來。**這次的經驗讓我確認了自己「以技術實踐創意」的特質。我具備在資源有限、時間緊迫的環境下，快速學習新技術並產出原型的能力**

**專案領導力**：講回專題的製作過程，新手帶領一群資安能力更強的人真的很瘋狂，身為開頭的人，從工作分配，到實作，甚至是檢查進度我都要負責，很多時候隊員交上來的東西不夠好我甚至要自己重寫，就比如其實是有人幫我寫提示詞跟調用ai的程式的，但這兩部分最後都是我自己重新寫過的才能拿來用，又比如我看到部署組卡關我也要去幫忙，攻擊組提示詞注入甚至也是我寫出來的。到最後我們的組內互評貢獻比例我甚至是40%/50%
似乎我的努力似乎也有被主辦方看見，後來我收到了通過一個高組別國際資安營的初選的email，全台灣只有30-35個人能被推薦，且一般都是高組別的ais3學生而不是junior才會被推薦，可惜那時候我在忙著準備考試就沒有準備後來的資料了

總的來說這是一個非常好的學習體驗，也是我開發者生涯裡一個很重要的歷程
