# GDG DevJam 2025 黑客松：跨領域協作與產品思維的啟蒙

**【介紹與專案背景】**
我以後端與 AI 應用工程師的身分參加了 Google Developer Groups on campus 舉辦的 DevJam 2025 黑客松。這次的團隊組成非常特別，由我負責後端與雲端，搭配一位負責前端的資工系學長，以及兩位負責企劃與簡報的文組學長姐。在比賽中，我們共同開發了「AI 海外留學顧問平台（申寶 SAMBOU）」，不僅解決留學資訊破碎與代辦昂貴的痛點，更在極限時間內完成了具備嚴謹系統架構與清晰邏輯的完整應用。

**【專案細節與挑戰突破】**
| 項目與面臨的挑戰 | 我的應對與專案細節 |
| :--- | :--- |
| **問題抽象化與模型化**：初期我執著於疊加複雜技術，但學長姐提醒應先釐清核心問題。 | 學會將現實中模糊的需求，透過邏輯分析抽象化，提煉出最核心的系統運作模型並加以實作。 |
| **極限開發與技術實作**：黑客松時間緊迫，且需整合最新的 AI 技術。 | 短時間內使用 FastAPI 建置後端，並成功串接 Gemini Deep Research 與 RAG 技術。 |
| **雲端部署卡關**：深夜遭遇 GCP 雲端權限卡關與前後端 API 串接陣痛期。 | 保持冷靜持續除錯，與前端隊友一路奮戰至凌晨四點，成功完成最終的系統整合。 |
| **跨領域團隊協作**：團隊成員包含純技術（資工系）與純企劃（文科系）背景。 | 完美發揮分工作用：我專注於技術與環境建置，企劃組專注於商業價值包裝與上台簡報。 |

**【能力成長與收穫】**
| 核心能力 | 成長細節與具體收穫 |
| :--- | :--- |
| **系統分析與邏輯思維** | 突破「為技術而技術」的盲點，學會從複雜混亂的資訊中抽絲剝繭，定義核心問題並設計嚴謹的演算法與系統架構來解決。 |
| **全端與 AI 實作** | 熟練運用 FastAPI 建置後端、整合 Gemini Deep Research 與 RAG 技術，並獨立克服 GCP 雲端部署難關。 |
| **跨領域團隊協作** | 學會與不同專業背景的隊友高效分工，深刻體會「技術並非一切，完美分工才能造就產品」的團隊價值。 |
| **邏輯推演與表達** | 透過觀摩學長姐的表現，學習如何將複雜的系統架構與技術邏輯，轉化為條理分明、極具說服力的論述，補足純開發者的弱項。 |

**【心得與反思：從技術堆疊到問題抽象化的思維升級】**
最終，我們靠著精準的問題定義與無懈可擊的團隊協作，奪下了 Gemini API 組的冠軍。這場比賽徹底翻轉了我對專案開發的認知。以前我總習慣從「我想實作什麼酷炫技術」出發，但我深刻明白，真正的技術創新必須建立在對核心問題的透徹理解之上。我學會了如何將一個複雜、模糊的現實痛點，透過邏輯分析將其「抽象化」與「模型化」，最終提出嚴謹且具備高度可行性的系統架構。

這次經驗不僅讓我跨出了純技術實作的舒適圈，建立起將現實問題轉化為系統邏輯的分析能力，也讓我親身見證了跨領域分工的威力。從學長姐身上觀摩到條理分明的邏輯推演與表達技巧，更是我在追求基礎科學與學術研究的道路上，不可或缺的軟實力升級。
