# devjam 2025
## 前言
在Google Developer Groups(gdg) on campus DevJam tw 2025 中，我以後端與ai應用工程師的身份，與組員們共同努力，幸運且驕傲地拿下了 Gemini API 組的第一名。這次的勝利帶給我最大的震撼與收穫，並非來自於我寫出了多麼複雜的架構，而是讓我深刻體悟到：**在產品導向的比賽裡，精準找出痛點、提供完整的解決方案與報告，遠比任何技術細節都來得重要。**
![20260328_163242](https://hackmd.io/_uploads/Sy_PMMSsZe.jpg)
## 開始
我們團隊的組成非常特別，除了我主動負責全部的後端與雲端部署，還有一位負責前端的清大資工學長，以及兩位負責企劃與簡報的政大文組學長姐。這次比賽的主題是「ESG+」，對我來說是一個相對陌生的領域。
在比賽初期的發想階段，我一直試圖拋出各種天馬行空、自認很酷的點子，但兩位政大的學長姐總能敏銳地找出這些點子在實務上的盲點。經過幾次來回，我坦白說有些不耐煩了，索性決定放手讓他們來決定主題，我專心當好開發的工具人就好。最終，他們決定做一款「海外留學顧問 AI」，功能涵蓋收集分散在各校的資料、輔助製作備審履歷、自製時間表以及自動提醒。當時，我心裡其實覺得這個點子非常普通，但為了推進進度，我還是點頭同意，並立刻投入開發。

## 挑燈夜戰的極限開發
進入開發階段後，我迅速用 python FastAPI 寫出最基礎的 AI 調用並生成 API 文檔，交接給負責前端的學長。隨後，我迎來了第一個挑戰：Google Cloud 的部署。在環境變數設定與連線權限上卡了很久，前前後後重新部署了一個多小時，才總算讓前端成功連線。
接下來在實作自動行事曆、檔案管理與文案輔助等進階功能時，開發節奏開始變慢。除了邏輯本身較為複雜，我與前端之間的溝通也出現了斷層，導致我們有很長一段時間是各做各的，缺乏有效合作。不過，黑客松的夜晚其實充滿挑戰卻又十分有趣。我可以一直拿免費的零食飲料，還能解鎖在各種奇怪地方寫程式的成就，我一路從原本的小組座位，換到坐在窗台的休息小床上繼續趕工。
政大的學長姐在8點左右先回去，剩下我跟交大的學長繼續努力。雖然過程中遇到了他不太熟悉 API 串接、我自己開發速度太慢等困難，但我們仍一路奮戰到午夜三點多。最終有驚無險地在凌晨四點完成最後的整合與測試，才稍微睡一下休息。

## 跨領域的完美分工
早上八點，政大的學長姐回來接手戰局，這也是他們大顯神威的時刻。他們在極短的時間內，將我們的產品轉化為架構明確、乾淨且漂亮的簡報。簡報中精準地打中了目標客群的痛點，並完整闡述了系統架構、未來展望與商業化計畫。這是我這種純技術人員絕對無法獨立完成的成果，我只能在旁邊幫忙修飾一些技術內容。
上台報告時，學長姐展現了極高的專業度，熟練地完成演說。報告的完整度甚至高到讓評審幾乎不需要再多問什麼問題，偶有提問也能完美應對。靠著這樣無懈可擊的表現，我們成功奪下了冠軍。


## 產品

我們最終開發出的產品名為「申寶 SAMBOU」，這是一個專為解決留學申請資訊不對稱與高昂仲介費而生的 AI 留學申請平台，產品的核心理念為：「搞定留學大小事，不用再戰第二次」。
![9](https://hackmd.io/_uploads/SJomBEnjWx.jpg)

產品設計與實作涵蓋了以下幾個核心面向：

1. **直擊市場痛點**
   瞄準出國留學意向明確的學生族群（台灣每年約 5.7 萬人，全球高達 100 萬人規模）。有效解決傳統留學代辦費用過於昂貴、各國留學政策與規定資訊碎片化，以及申請文件繁雜難以管理的三大痛點。

2. **三大核心功能與技術架構**
   - **AI 顧問建檔**：透過 Agentic Flow 與 Characterization 技術，引導用戶輸入 GPA、競賽、研究與工作經驗，建立完整的專屬學術檔案。
   - **資料搜集與選校媒合**：結合 Gemini Deep Research 與 RAG（檢索增強生成）技術，依照用戶的個人檔案進行校系精準媒合評分（例如：評估加州大學柏克萊分校錄取率為 9.5 分）。
   - **文件管理與自動潤稿**：採用 Angular SPA 前端與 Flask API 後端架構，並由我負責部署於 GCP (Google Cloud Platform)。資料庫使用 NoSQL (Firebase) 儲存管理，同時利用 LLM 優勢提供 SOP（目的陳述）的深度修改建議與寫作指南。

3. **強大的技術優勢**
   我們接入當時最先進的 Gemini 2.5 模型，具備高達 128k tokens 的超大上下文視窗，能輕鬆處理多輪對話與長篇申請文件而不遺漏任何資訊。不僅在「Humanity's Last Exam」等測試中展現頂尖推理能力，其極具競爭力的 API 成本（優於 Claude 或 GPT-4o 等競品）也讓我們的服務更有機會普及。

4. **商業模式與社會願景**
   平台採 Freemium（免費增值）模式配置：基礎 AI 顧問與選校分析免費，進階進度排程與文書優化則採付費訂閱制。未來除了與語言學校、航空金融業等進行異業結盟，也能對接政府的「青年百億海外圓夢計畫」。長遠目標是建立 AI 驅動的教育生態系，實踐 SDGs 消除貧窮與優質教育的社會影響力。

## 反思：技術之外的產品思維
這次的經驗徹底翻轉了我對「做專題」的認知。以前我想題目的時候，總是習慣先從「我想做什麼功能」出發，但經過這次比賽，我明白訂題目必須從「有數據證明的真實痛點」出發，而不是開發者自己想出來的假性痛點。確認目標客群後，再提出具備可行性的解決方案，並證明它真的能解決問題。
在這種以產品為主的比賽中，只要契合主題、選擇簡單但扎實的題目，並把「問題與解決方案」設計好，就能取得好成績。不需要冒險去做前所未見或是異想天開的產品，即便是看似普通的點子，只要能確實解決痛點，就是一個好的專題。我一定會把這次學到的經驗，應用在未來所有產品導向的專題比賽中。
同時，我也學到了進階的團隊合作。一開始，因為兩位政大的學長姐沒有充足的開發經驗，交大的學長也主要依賴 Vibe Coding 寫前端，我原本對得獎不抱期望。但事實告訴我，技術並不代表一切，就算有技術，無法做出好產品也無法獲勝。我們這組達成了最完美的分工合作：懂技術的專心搞技術，懂企劃的專心搞定文案與簡報。在與學長姐交流及觀摩的過程中，我也從旁學會了如何製作一份架構明確、直擊痛點且極具說服力的簡報，彌補了我以往只專注程式開發的不足。大家都在自己擅長的領域發揮到極致，最終在有限的時間內，完成了這個冠軍產品。
