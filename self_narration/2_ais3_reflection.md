# AIS3 Junior 資安培訓：從初學者到大滿貫得主的實戰與反思

**【介紹與專案背景】**
高二下學期，帶著自學全端開發的基礎，我以資安初學者的身分參加了 AIS3 Junior 資安培訓營。在最終的專題實作中，我因主動提出「將 AI 助手結合訂單管理網站，並利用提示詞注入復現漏洞」的創新構想，而被推舉為組長，帶領一群資安能力比我強且經驗豐富的組員。在不到 24 小時的極限開發中，我負責統籌任務分工，並親自完成了大部分的前端互動與後端架構開發。這次營隊對我來說是一場跨越舒適圈的挑戰。

**【面臨的挑戰與應對策略】**
| 遇到的挑戰 | 我的應對與解決方案 |
| :--- | :--- |
| **環境配置碰壁**：首日遇到 Linux 虛擬機與 VPN 設定卡關，進度嚴重落後 | 保持冷靜，尋求隊友協助並快速重灌系統，隨後迅速跟上課程進度。 |
| 高難度 CTF 挑戰需在短時間內解出高難度資安進階題以獲取結業資格 | 深夜與室友共同熬夜解題，憑藉毅力與快速學習，最終衝上排行榜第七名。 |
| **專案方向卡關**：小組討論許久仍無結論，且自己身為初學者面對資優組員 | 主動提出「AI 助手結合電商網站與漏洞復現」的創新構想，成功確立目標並被推舉為組長。 |  
| **帶領資深團隊**：帶領團隊時組員資安能力皆比我強且經驗豐富 | 學會拆分任務、分配並監督工作，在溝通中傾聽意見並發揮團隊影響力。 |
| **極限開發壓力**：必須在不到 24 小時內完成專案實作 | 作為溝通橋樑協調攻防需求，並親自完成前端與後端架構的開發。 |
| **系統整合瓶頸**：團隊交付的程式碼遇到相容錯誤與瓶頸 | 迅速接手除錯與重構，確保專案系統在時限內成功部署與上線。 |

**【反思與成長：一場充滿挑戰的蛻變】**
最終，我們組獲得了最佳專題獎第一名，而我也因為貢獻較多被另外提名為優秀個人，成為當屆唯一的大滿貫（第一名+優秀個人）學生。

這次經歷讓我發現了自己作為領導者的潛力，也讓我相信自己的創意能力是可以被認可的。在與組員的合作中，我學會了如何傾聽他人的意見，並在團隊中發揮自己的影響力。這些經驗不僅提升了我的技術能力，更讓我在溝通、協作和領導方面有了顯著的成長。

回顧這段歷程，我發覺到自己的優勢在於能夠在資源有限、時間緊迫的高壓環境下，快速學習新技術並將創意轉化為實際的系統原型。此外，我也學習到專案領導的核心不在於個人技術是否最頂尖，而在於能否準確分配資源、補足團隊短板，並帶領團隊朝共同目標邁進。AIS3 真的是我高中最引以為傲的一件事，那些熬夜 debug 的夜晚、卡關時的崩潰，還有終於跑通程式時的快感，都讓我感受到自己的成長。我確實地在其中學到了很多也拓了我的技術視野，並發掘了自己的潛力與自信。
