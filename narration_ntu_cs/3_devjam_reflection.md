# GDG DevJam 2025 黑客松：跨領域協作與產品思維的啟蒙

**【介紹與專案背景】**
我以「後端與 AI 應用工程師」的身分參加了 Google Developer Groups 舉辦的 DevJam 2025 黑客松。這次的團隊組成非常特別，由我負責後端與雲端，搭配一位負責前端的資工系學長，以及兩位負責企劃與簡報的文組學長姐。在比賽中，我們共同開發了「AI 海外留學顧問平台（申寶 SAMBOU）」，不僅解決留學資訊破碎與代辦昂貴的痛點，更在極限時間內完成了具備清晰商業模式的完整產品。

**【專案細節與挑戰突破】**
| 項目與面臨的挑戰 | 我的應對與專案細節 |
| :--- | :--- |
| **技術執著與需求盲點**：初期我執著於高難度技術，但學長姐指出缺乏市場真實需求。 | 放下「為技術而技術」的盲點，接受以「解決真實痛點」為核心的產品開發導向。 |
| **極限開發與技術實作**：黑客松時間緊迫，且需整合最新的 AI 技術。 | 短時間內使用 FastAPI 建置後端，並成功串接 Gemini Deep Research 與 RAG 技術。 |
| **雲端部署卡關**：深夜遭遇 GCP 雲端權限卡關與前後端 API 串接陣痛期。 | 保持冷靜持續除錯，與前端隊友一路奮戰至凌晨四點，成功完成最終的系統整合。 |
| **跨領域團隊協作**：團隊成員包含純技術（資工系）與純企劃（文科系）背景。 | 完美發揮分工作用：我專注於技術與環境建置，企劃組專注於商業價值包裝與上台簡報。 |

**【能力成長與收穫】**
| 核心能力 | 成長細節與具體收穫 |
| :--- | :--- |
| **產品與商業思維** | 突破「為技術而技術」的盲點，學會從「有數據支持的真實痛點」出發，設計具備商業價值的產品。 |
| **全端與 AI 實作** | 熟練運用 FastAPI 建置後端、整合 Gemini Deep Research 與 RAG 技術，並獨立克服 GCP 雲端部署難關。 |
| **跨領域團隊協作** | 學會與不同專業背景的隊友高效分工，深刻體會「技術並非一切，完美分工才能造就產品」的團隊價值。 |
| **簡報架構與表達** | 透過觀摩企劃組學長姐的表現，學習如何製作直擊痛點且極具說服力的商業簡報，補足純開發者的弱項。 |

**【心得與反思：從寫程式到做產品的思維升級】**
最終，我們靠著精準的產品定位與無懈可擊的團隊協作，奪下了 Gemini API 組的冠軍。這場比賽徹底翻轉了我對做專題的認知。以前我總習慣從「我想寫什麼功能」出發，但現在我深刻明白，好的專案必須從「有數據支持的真實痛點」出發而不是從我覺得有趣的功能出發。且我了解到一個成功的專題不需要前所未見的酷炫技術，只要能扎實地提出具備可行性的解決方案，就是好產品。

這次經驗不僅讓我跨出了純技術開發的舒適圈，建立起寶貴的「產品思維」，也讓我親身見證了跨領域分工的威力。從學長姐身上觀摩到的高水準簡報結構與表達技巧，將是我未來面對所有專案開發時，最重要的軟實力升級。
