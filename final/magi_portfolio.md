# Magi：多智能體協作框架的架構設計與開放原始碼學習歷程

## 這是什麼 && 我學到了什麼
這個項目的宗旨是打造一個名為「Magi」的多智能體協作框架（Multi-agent framework），讓由 LLM 驅動的多個 Agent 能互相協作，解決複雜的寫程式與終端機任務。系統中的所有 Agent 皆為**同等級的代理**，每個實例都具備相等的權限、共享相同的核心工具集，並擁有彼此獨立的記憶與上下文機制。

在這段開發歷程中，我學到了：
- **Agentic 架構設計**：學習如何設計去中心化的多智能體系統。了解如何實作同級 Agent 之間的訊息傳遞機制，以及建立階層化的雙層記憶架構。
- **研讀開源專案**：學會參考與借鑑其他開源專案的程式直覺與寫作格式，了解如何將複雜的 PTY 終端機支援、工具調用封裝化。
- **結構化思考與提示詞工程**：透過 Pydantic 定義資料結構（`AgentStep`），強制模型進行思維鏈分析 (Chain-of-Thought)，提升系統輸出的穩定度並減少幻覺。

## Agentic 架構設計思維
在開發初期，如果只用單一個強大的 Agent 來處理所有事情，當任務變得複雜（如長期的終端機腳本執行、除錯、編輯程式碼等）時，很容易超出 Token 限制並導致邏輯混亂。因此我將架構設計為「多智能體分散式模式」。

當面對複雜工作時，任何現有的 Agent 都可以利用 `make_new_agent` 工具動態創建新的同等級智能體來分擔任務。這不是上對下的從屬關係，而是平行的工作夥伴。智能體之間透過 `send_message` 工具進行溝通，甚至可以使用 `edit_stm` 直接修改同伴的短期記憶，這樣不僅讓工作能沙盒化執行，也讓每個 Agent 都能在同等級的基礎上各司其職，維持獨立且清晰的思考邏輯。

## 開源專案 (Open Source) 的研讀與借鑑
這個專案中最具挑戰的部分是底層工具整合與狀態管理。為了實作這個系統，我花了很多時間詳細研究其他開源專案的模型架構與原始碼，學習他們的開發模式與設計模式（Design Patterns）。

例如，在處理終端機互動時，我參考了開源專案對於 `pty` (偽終端) 的實作，寫出了 `pty_manager.py`，讓 Agent 不只是「跑一次指令」，而是能與需要長時間運行的 CLI 程式互動（發送 stdin、檢查 stdout 狀態）。我也參考了其他知名項目的記憶管理機制，將文件結構與功能代碼徹底分離，這些透過研讀 Open Code 學習到的經驗大大縮短了開發時間。

## 核心系統實作
### 雙層記憶系統 (STM 與 LTM)
為了讓每個平級的 Agent 都有長期解決問題的能力，我實作了兩層式的記憶架構：
- **短期記憶 (STM)**：存在記憶體內的臨時文字字串。Agent 可以利用 `remember()` 記下重點。當對話超過一定字數（`MAX_STM_LENGTH`），系統會利用 LLM 自動將歷史紀錄進行壓縮。
- **長期記憶 (LTM)**：用 Markdown 檔案搭配 YAML Frontmatter 存放於 `ltm/` 中。其中的 YAML 標籤（如 `active_for`, `visible_to`, `except_for`）可以設定這段記憶是對哪個 Agent 可見，甚至直接注入 System Prompt。由於所有 Agent 平級，這些記憶可以被針對性地分享或隔離。

### 結構化行為控制 (Pydantic Schema)
我結合了 Pydantic 來確保模型每一次的呼叫一定吐出預期的格式。每次動作都強制包含反思與下一步計畫，這讓整個系統的除錯過程變得清晰，且 Agent 的行為更具可預測性。

## 目前的問題與挑戰
- **上下文遺失與失焦**：儘管有了短期記憶壓縮機制，但在面臨極度漫長的終端機輸出時，Agent 還是偶爾會忽視 LTM 中的關鍵指示。
- **多智能體之間的狀態競爭**：由於多個 Agent 處於同等級平行運作，當他們頻繁與相同的環境（如檔案系統或終端機）進行互動時，會產生狀態競爭的問題，未來需要引入更好的鎖定機制或是非同步（Async）管理器。

## 心得與反思
開發 Magi 是我第一次將「Agentic」這種高階人工智慧設計思維落實為實際的軟體架構。在開發過程中，我不斷遇到瓶頸，但也因此**學會了放下自己重新造輪子的執著，轉而積極從優質的開源專案 (Open Code) 中吸取養分。** 

透過閱讀開源原始碼，我不僅學到了更優雅的物件導向抽象化方式（例如將工具與 Prompt 分離），也讓我在系統設計的心態上產生了轉變。我深刻體會到，一個好的軟體工程師，除了能從零建構系統外，更需要具備快速理解、吸收並整合前人智慧的能力。這次的歷程不僅讓我在架構設計上有長足進步，也為我未來開發複雜的 AI 協作程式打下了堅實的基礎。
